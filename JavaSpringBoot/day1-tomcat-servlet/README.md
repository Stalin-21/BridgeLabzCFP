# Day 1 – Tomcat & Servlet

## Use Case 1: User Registration

### Description
A simple user registration flow using Java Servlet and HTML.

### Flow
- User opens `register.html`
- Submits name, email, and password
- Servlet processes POST request
- Success response is displayed

### Technologies
- Java 21
- Servlet API
- Apache Tomcat 9
- IntelliJ IDEA Ultimate

### URL
http://localhost:8080/day1-tomcat-servlet/register.html
